## Overview

This repository documents **10 digital forensics investigations** completed as part of MAC 257 at LaGuardia Community College. The lab series covers evidence handling, incident response, host forensics, mobile forensics, network forensics, memory forensics, steganography analysis, and recovery of deleted or damaged data.

The purpose of this repository is to preserve the original investigation reports while making the scope of the work, tools used, and skills demonstrated easy to review.

## Investigation Coverage

- Forensic evidence evaluation and the **Daubert Standard**
- **Steganography** detection and analysis
- Recovery of **deleted and damaged files**
- **Incident response** investigation
- **Windows** system forensics
- **Linux** system forensics
- **Email and chat log** forensics
- **Mobile device** forensics
- **Network infrastructure** forensics
- **System memory** forensics
